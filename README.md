# 声控滑动助手

一款原生 Android 无障碍辅助应用。通过“请往上滑 / 请往下滑 / 请往左滑 / 请往右滑”等语音指令，在当前前台应用中模拟滑动手势。

当前版本：`v1.3.0`。安装包可在 [GitHub Releases](https://github.com/kayeung/voiceControl/releases/latest) 下载。

## 功能

- 默认使用内置 Vosk 中文离线识别，不依赖厂商语音服务，音频仅在本机处理。
- 可切换系统 `SpeechRecognizer`；系统识别连续无回调时自动回退离线引擎。
- 自动纠正常见近音误识别，如“往上爬”“向上划”“网上滑”“往左华”。
- 嘈杂环境增强模式：限制离线识别词表，并要求先说出唤醒词，降低广告人声误触发。
- 前台服务后台监听，通知栏可随时停止；识别异常按退避策略自动恢复。
- 无障碍服务执行上、下、左、右手势，支持横竖屏实时坐标适配。
- 单个快捷设置磁贴：一键启动语音监听，并在首次使用时引导完成无障碍授权。
- 支持可选唤醒词、自定义指令别名、滑动距离和手势时长。
- 展示语音、无障碍、屏幕方向状态以及最近 100 条运行日志。
- 提供四个方向的手动测试按钮。

## 环境

- Android Studio（支持 Android Gradle Plugin 8.7）
- JDK 17 或兼容版本
- Android SDK 35
- 最低系统：Android 7.0（API 24）
- 目标系统：Android 15（API 35）
- 已在 Android 16 与 vivo OriginOS 实机验证
- 安装包约 65 MB，内置中文离线模型

## 使用

1. 安装并打开应用，点击“启用无障碍服务”，在系统设置中允许“声控滑动助手”。
2. 返回应用，按需修改指令、唤醒词和手势参数。默认开启“优先使用离线识别”，点击“保存设置”。
3. 点击“开始语音监听”，授予麦克风和通知权限。首次使用离线识别需要几秒加载内置模型。
4. 切换到目标应用，说出“请往上滑”等指令。保持前台服务通知存在即可在后台监听。
5. 在通知栏点击“停止监听”，或返回应用停止。

### 嘈杂环境/外放广告

可在语音设置中开启“嘈杂环境增强（需唤醒词）”，保存后重新开始监听。然后使用：

```text
小助小助，请往上滑
```

该模式会限制离线识别词表并强制校验唤醒词，避免视频广告里的普通对话被当成滑动指令。外放音量较大或手机离嘴较远时，仍建议使用有线/蓝牙耳机麦克风，或让手机靠近嘴边；软件无法恢复被广告声覆盖的语音细节。

### 近音纠错

默认指令匹配会自动处理常见近音/误识别：

- `往上爬 / 向上划 / 网上滑` → 上滑
- `往下趴 / 向下划` → 下滑
- `往左华` → 左滑
- `向右画` → 右滑

纠错只发生在“方向字 + 滑动词”的上下文中，不会把普通广告语句随意转换成滑动命令。

## 快捷磁贴

应用提供一个“声控滑动”快捷设置磁贴：

- 点击后启动语音监听；如果无障碍服务尚未授权，会在同一次操作中打开系统无障碍设置页。
- 首次完成无障碍授权后，后续点击磁贴即可一键恢复语音监听，无需重新配置。
- 磁贴显示为绿色高亮表示“语音与无障碍已就绪”；再次点击会停止语音监听，不会擅自关闭系统无障碍服务。
- Android 13 及以上可在应用内点击“添加一键启动磁贴”，系统会弹出添加提示。
- Android 7–12 或厂商未实现添加提示时：下拉控制中心 → 点击编辑/铅笔按钮 → 将“声控滑动”拖入快捷开关。
- 磁贴采用标准 `TileService`，兼容 vivo OriginOS、小米 HyperOS/MIUI、魅族 Flyme 等主流系统。vivo 已完成实机验证；小米、魅族使用相同标准接口，若未自动显示请按下拉编辑方式手动添加。

Android 安全模型禁止第三方应用静默开启无障碍服务，因此首次授权必须由用户在系统页面确认一次；这是系统限制，无法由应用绕过。

## 已知限制

- 嘈杂模式依赖唤醒词才能触发，且唤醒词建议使用 2 个以上常用汉字；修改设置后需要重新开始监听。
- 嘈杂模式通过 Vosk 小模型词元约束提高稳定性，不是强降噪算法；外放音量远高于人声时，请使用耳机麦克风或靠近手机说话。
- 中文小模型无法直接使用整句动态语法，因此项目采用“受限词元 + 本地完整指令/唤醒词校验”，不牺牲广告声下的误触发安全性。
- APK 仍使用调试证书签名，适合侧载测试；正式分发前需要配置自有签名。

## 实现说明

- `CommandParser` 在本地对识别文本做 Unicode 标点/空白清理、方向近音纠错和短语匹配，不保存音频。
- 离线引擎使用 Vosk 持续识别，只在最终句结果产生后执行手势，避免同一句话触发多次滑动；同方向指令冷却 2 秒。
- 嘈杂模式通过 Vosk 词元级限制词表；由于中文小模型不支持整句短语语法，应用仍用本地解析器校验完整唤醒词和指令，防止广告人声误触发。
- 离线模型打包在 APK 中，首次启用时复制到应用专属目录。系统识别无回调时自动切换离线识别并记住该选择。
- 每次手势都读取当前显示尺寸，竖向手势按屏高计算距离，横向手势按屏宽计算距离，因此旋转后无需重启服务。
- Android 14 及以上声明麦克风前台服务类型。首次启动应从可见的应用界面发起。
- 应用不申请网络权限；系统识别模式由厂商服务处理，是否联网取决于该系统服务。
- 无障碍服务仅订阅窗口状态变化，回调不读取事件数据；不订阅屏幕内容变化，也不收集屏幕内容。某些视频应用可能限制系统手势，实际效果以目标应用为准。
